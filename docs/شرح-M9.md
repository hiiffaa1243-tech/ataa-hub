# شرح المرحلة M9 — التلميع والإثبات

هدف هذه المرحلة: أي شخص يشغّل `docker compose up` على جهاز نظيف يرى جمعية "حيّة" فيها بيانات وهمية تكفي لعرض المشروع كاملاً في 7 دقائق.

---

## 1) بيانات العرض (`setup/demo.py`)

```bash
bench --site <site> execute ataa_hub.setup.demo.seed
```

تعمل تلقائياً عند أول تشغيل لـ Docker (إلا إذا وضعتِ `DEMO_DATA=0`)، وعلى المواقع المحلية فقط. فيها:

| ماذا | التفاصيل |
|---|---|
| موظفون | المدير التنفيذي، المحاسبة، مديرا مشاريع (كل واحد يرى مشاريعه فقط). كلمة المرور `Ataa@Demo2026` |
| متبرعون وهميون | أرقام `05000001xx` وبريد `.test` لا يصل لأحد |
| 22 تبرعاً على 3 أشهر | تحويلات بنكية (منها 2 بانتظار التحقق)، طلبات متجر، 7 تبرعات نقاط بيع في جناح برج الساعة خلال الساعات الأخيرة، هديتان |
| طلبات صرف | طلب في **كل** حالة: مسودة، بانتظار المحاسب، بانتظار المدير، معتمد، مرفوض، مصروف |
| تخصيص | من الصندوق العام لمشروع الضيافة، بانتظار المدير |
| أعضاء | ذهبي، فضي، برونزي، وعضو ذهبي "بانتظار الدفع" بعد محاولة خصم مرفوضة |

تشغيلها مرة ثانية **لا يكرر** البيانات. و`setup.demo.summary` يطبع الأرصدة وقيم البطاقات وسجل الموافقات للطلب المصروف.

## 2) CI أقوى

بعد الاختبارات، GitHub Actions الآن يبني **موقع عرض نظيفاً** ويشغّل بيانات العرض مرتين ثم الملخص. فلو كسر أي تعديل بيانات العرض نعرف فوراً.

## 3) تجربة هيئة الزكاة (Sandbox)

على موقع العرض في Codespace ثبّتنا `ksa_compliance` وربطناه ببيئة الهيئة التجريبية:
- حصلنا على شهادة الامتثال وشهادة الإنتاج (بالـ OTP التجريبي).
- فاتورة عضوية برونزية (50 ريال، منها 6.52 ضريبة) → **قُبلت مع تنبيه** واحد: إضافة رقم السجل التجاري للبائع.
- قالب الطباعة عرض رمز QR الكامل من التطبيق (9 حقول).

ما أصلحناه أثناء التجربة: `ksa_compliance` يحتاج **فئة ضريبية** على قالب الضريبة، فصارت `setup_sandbox_demo` تضيفها. وفك رمز QR صار يتعامل مع الحقول الثنائية (التوقيع والمفتاح العام).

## 4) الوثائق

- `README.md` الإصدار الثاني: ماذا يفعل، رحلة الريال، التشغيل، الحسابات التجريبية، التقارير، الاختبارات.
- `docs/ACCEPTANCE.md`: كل معيار قبول في PRD ومعه الاختبار أو التجربة التي تثبته، وبصراحة ما تحقق جزئياً.
- `docs/شرح-المشروع.md` الإصدار الثاني: الشرح العربي الكامل وأسئلة المقابلة.

## 5) ما بقي عليكِ

- لقطات شاشة أو فيديو قصير للعرض (يحتاج تشغيلاً على جهازك).
- لإزالة تنبيه الهيئة: إضافة سجل تجاري (وهمي في العرض) في ZATCA Business Settings.
